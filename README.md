# Nice Catch AI website

Live site: https://getnicecatch.com
Hosting: Cloudflare Pages, auto-deploys from the `main` branch of this repo.

## Where to change things
- Everything is in `index.html`: copy, styles, and the structured data block near the top
  (business details, services, questions and answers, social profile links).
- `robots.txt` and `sitemap.xml` are for search engines and AI crawlers.
